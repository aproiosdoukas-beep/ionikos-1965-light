# Ιωνικός Νικαίας 1965 — UI/UX Mockup (App & Web) 2026

Διαδραστικό mockup για **έναν σύλλογο**: την επίσημη εφαρμογή κινητού και την
ιστοσελίδα του Ιωνικού Νικαίας. Υλοποιημένο σε απλή HTML/CSS/JS, χωρίς build step
και χωρίς backend — όλα εκτελούνται τοπικά στον browser.

Βασισμένο στο *«Ιωνικός 1965 • UI/UX App & Web Showcase 2026»*.

---

## Τα QR είναι πραγματικά

Δεν είναι εικόνες — παράγονται στον browser με τη βιβλιοθήκη
[`qrcode-generator`](https://github.com/kazuhikoarase/qrcode-generator) (MIT) και
σαρώνονται κανονικά από οποιοδήποτε κινητό.

**Μορφή token**

```
ION1|<κωδικός κάρτας>|<παράθυρο 60s>|<υπογραφή FNV-1a>
```

* Ανανεώνεται **αυτόματα κάθε 60 δευτερόλεπτα**, ευθυγραμμισμένο με το ρολόι,
  ώστε κάρτα και scanner να συμφωνούν χωρίς server.
* Το countdown στην κάρτα δείχνει τα δευτερόλεπτα που απομένουν.
* Ο scanner δέχεται το τρέχον **και** το προηγούμενο παράθυρο (grace 60s), όπως κάθε TOTP.

**Τι επαληθεύει πραγματικά ο scanner θύρας**

| Περίπτωση | Αποτέλεσμα |
|---|---|
| Έγκυρο, φρέσκο token | `ΕΓΚΥΡΗ ΚΑΡΤΑ` — +1 πόντος badge «Παρών» |
| Ίδια κάρτα δεύτερη φορά την ίδια ημέρα | `ΗΔΗ ΣΑΡΩΜΕΝΗ` — απαγόρευση 2ης εισόδου |
| Κάρτα σε περίοδο χάριτος | `ΛΗΓΜΕΝΗ ΣΥΝΔΡΟΜΗ` |
| Token παλαιότερο των 120s | Απόρριψη (έληξε) |
| Αλλοιωμένη υπογραφή | Απόρριψη (πλαστό) |

Δοκιμή από άκρο σε άκρο: ανοίξτε το `app.html` σε μια καρτέλα και το `scanner.html`
σε άλλη, αντιγράψτε το token (είναι στο `data-token` του QR) και επικολλήστε το.

> Η υπογραφή είναι FNV-1a με σταθερό secret μέσα στον client — αρκεί για επίδειξη,
> **δεν** είναι κρυπτογραφικά ασφαλής. Σε πραγματική υλοποίηση: HMAC-SHA256
> με secret στον server.

## Σύστημα σχεδίασης

Ένα σύνολο tokens και components τροφοδοτεί **και** τα δύο mockups, ώστε τα
κουμπιά και οι κάρτες να είναι πανομοιότυπα παντού.

* `assets/css/tokens.css` — χρώματα, τυπογραφία, αποστάσεις, σκιές
* `assets/css/components.css` — κουμπιά, κάρτες, chips, badges, πεδία, πίνακες
* `assets/css/shell.css` — κέλυφος κινητού, ιστοσελίδας, admin
* `assets/css/app.css` — ειδικά μπλοκ (κάρτα μέλους, scanner, player, chat)

**Παλέτα** (δειγματοληπτημένη από το showcase)

| Ρόλος | Hex |
|---|---|
| Navy συλλόγου | `#1A3668` |
| Χρυσό accent | `#D3AF37` |
| Ink / κάρτες σε dark | `#0F172A` |
| Βαθύ φόντο | `#060C1A` |
| Surface raised | `#1E293B` |
| Ανοιχτό φόντο | `#F1F4F9` |
| Επιτυχία | `#10B981` |
| Σφάλμα | `#EF4444` |

**Κουμπιά** — ένα base `.btn` με variants `--primary`, `--gold`, `--success`,
`--danger`, `--ghost`, `--outline` και μεγέθη `--sm`, `--lg`, `--block`, `--icon`.

## Εκτέλεση τοπικά

Δεν χρειάζεται build. Οποιοσδήποτε static server:

```bash
python3 -m http.server 8080
```

Έπειτα ανοίξτε `http://localhost:8080`.

> Το άνοιγμα με `file://` λειτουργεί επίσης, αλλά ένας server είναι προτιμότερος
> γιατί το `localStorage` μοιράζεται σωστά μεταξύ των σελίδων.

## Τι *δεν* κάνει

* Δεν υπάρχει backend, βάση δεδομένων ή API.
* Δεν γίνεται καμία πραγματική πληρωμή — τα κουμπιά Stripe/Viva είναι εικονικά.
* Δεν υπάρχει πραγματικό βίντεο· ο player είναι εικαστικός.
* Η κατάσταση (σαρώσεις, ψήφοι, εγκρίσεις) αποθηκεύεται στο `localStorage` του
  browser και μηδενίζεται με καθαρισμό δεδομένων ιστότοπου.
