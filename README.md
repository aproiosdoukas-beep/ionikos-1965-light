# Ιωνικός Νικαίας 1965: Εφαρμογή & Ιστοσελίδα

Διαδραστικό πρωτότυπο για τον Ιωνικό Νικαίας: η εφαρμογή για κινητό και η
ιστοσελίδα του συλλόγου, με κοινή σχεδίαση. Απλή HTML, CSS και JavaScript,
χωρίς build και χωρίς διακομιστή. Όλα εκτελούνται στον browser.

Αυτή είναι η φωτεινή μοντέρνα εκδοχή (assets/css/light.css πάνω στο modern.css): λευκό θέμα, γραμματοσειρά Inter, γυάλινη πλοήγηση.
Το θέμα βρίσκεται στο `assets/css/modern.css`. Η αρχική εκδοχή «heritage matchday»
συνεχίζει στο https://aproiosdoukas-beep.github.io/ionikos-1965-mockup/.

**Live:** https://aproiosdoukas-beep.github.io/ionikos-1965-mockup/

## Η συνδρομή αλλάζει πραγματικά

Κάθε λογαριασμός μέλους έχει δική του συνδρομή. Στο `web.html#subscription`
το συνδεδεμένο μέλος μπορεί να:

* αλλάξει ανάμεσα σε μηνιαία και ετήσια χρέωση (12 μήνες στην τιμή των 10)
* προσθέσει μέλος, ενήλικα ή παιδί ακαδημίας με τμήμα, που παίρνει δική του κάρτα
* αφαιρέσει μέλος, οπότε η κάρτα του δεν ανοίγει πια τη θύρα
* βάλει τη συνδρομή σε παύση και αργότερα να την επανενεργοποιήσει
* πληρώσει επιλέγοντας κάρτα, Apple Pay ή Viva Wallet (χωρίς πραγματική χρέωση)

Κάθε αλλαγή φαίνεται παντού: στην εφαρμογή, στον έλεγχο θύρας και στο ταμείο.
Η «Επαναφορά» στο προφίλ επιστρέφει τα δεδομένα στην αρχική τους μορφή.

## Οι κωδικοί QR

Παράγονται στον browser με τη βιβλιοθήκη
[`qrcode-generator`](https://github.com/kazuhikoarase/qrcode-generator) (MIT)
και σαρώνονται κανονικά από οποιοδήποτε κινητό.

```
ION1|<κωδικός κάρτας>|<παράθυρο 60 δευτερολέπτων>|<υπογραφή>
```

* Ο κωδικός αλλάζει αυτόματα κάθε 60 δευτερόλεπτα και η κάρτα δείχνει την αντίστροφη μέτρηση.
* Ο έλεγχος θύρας δέχεται τον τρέχοντα και τον προηγούμενο κωδικό, όπως τα TOTP.
* Παλιό στιγμιότυπο οθόνης ή αλλοιωμένος κωδικός απορρίπτεται.

| Περίπτωση | Αποτέλεσμα στη θύρα |
|---|---|
| Έγκυρος κωδικός | ΕΓΚΥΡΗ ΚΑΡΤΑ, +1 πόντος στο παράσημο «Παρών» |
| Ίδια κάρτα δεύτερη φορά την ίδια μέρα | ΗΔΗ ΣΑΡΩΜΕΝΗ |
| Συνδρομή σε παύση | ΛΗΓΜΕΝΗ ΣΥΝΔΡΟΜΗ |
| Παλιός, πλαστός ή άγνωστος κωδικός | ΜΗ ΕΓΚΥΡΟ QR |

> Η υπογραφή είναι FNV-1a με σταθερό κλειδί μέσα στη σελίδα. Αρκεί για παρουσίαση,
> δεν είναι κρυπτογραφικά ασφαλής. Σε πραγματική εφαρμογή χρειάζεται HMAC-SHA256
> με το κλειδί στον διακομιστή.

## Σχεδίαση

Ένα σύνολο από tokens και components τροφοδοτεί και τα δύο προϊόντα, ώστε
κουμπιά, κάρτες και πεδία να είναι ίδια παντού.

* `assets/css/tokens.css`: χρώματα, τυπογραφία, αποστάσεις
* `assets/css/components.css`: κουμπιά, κάρτες, παράθυρα, λίστες
* `assets/css/shell.css`: πλαίσιο κινητού, ιστοσελίδας, διαχείρισης
* `assets/css/app.css`: κάρτα μέλους, έλεγχος θύρας, player, chat

Τα χρώματα προέρχονται από το έμβλημα του συλλόγου:

| Ρόλος | Hex |
|---|---|
| Μπλε Ιωνικού | `#343795` |
| Χρυσό | `#CF9C1D` |
| Σκούρο φόντο | `#060C1A` |
| Ανοιχτό φόντο | `#F1F4F9` |
| Επιτυχία | `#10B981` |
| Σφάλμα | `#EF4444` |

Το έμβλημα βρίσκεται στο `assets/img/crest.svg` (διανυσματικό) και
χρησιμοποιείται σε κάθε σελίδα και ως favicon.

## Τοπική εκτέλεση

```bash
python3 -m http.server 8080
```

Μετά ανοίξτε το `http://localhost:8080`.

## Τι δεν κάνει

* Δεν υπάρχει διακομιστής ή βάση δεδομένων.
* Δεν γίνεται καμία πραγματική πληρωμή.
* Ο player είναι εικαστικός, δεν παίζει βίντεο.
* Τα δεδομένα αποθηκεύονται στο `localStorage` του browser.
